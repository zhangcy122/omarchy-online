# Change Proposal: clean-desktop-show-desktop-toggle

## Why
用户希望“完整显示桌面”（方式 1）：
1. **纯净开机桌面**：此前应用在启动时会自动弹出一个终端窗口，遮挡了 Omarchy 精美的原生壁纸与桌面视觉。用户希望开机或刷新页面后，默认呈现完整的、无遮挡的原生桌面与居中 Omarchy 标志；
2. **一键显示桌面 (SUPER + D)**：在打开一个或多个终端窗口后，用户需要随时快速隐藏所有窗口查看桌面壁纸与系统状态，并能一键快速恢复；
3. **顶栏显式交互入口**：除了快捷键外，顶栏应提供显式的“🖥️ 桌面”切换按钮，避免用户在未熟悉快捷键或浏览器快捷键发生冲突时迷失；
4. **防按键拦截的温和关闭**：在 macOS/Chrome 等浏览器环境下，`Cmd+W` / `Ctrl+W` 容易被浏览器优先拦截用于关闭浏览器标签页。必须 (MUST) 强化窗口标题栏关闭按钮（🔴）及追加兼容性热键（`SUPER + C`、`SUPER + Q`）。

## What
本提案必须 (MUST) 实施以下核心特性：
1. **默认开机桌面纯净化 (`web/app.js`)**：
   - 取消初始化时强制自动派生窗口的行为，开机默认呈现完整的桌面壁纸与 Omarchy 水印；
   - 提示用户随时按下 `SUPER + RETURN` 或点击 Walker 启动器一键生成平铺终端。
2. **全局“显示桌面 / 隐藏窗口”切换引擎 (SUPER + D)**：
   - 实现 `toggleShowDesktop()` 函数，记录并切换当前工作区的窗口显隐状态；
   - 隐藏时：平滑隐藏当前工作区全部窗口，完全露出桌面壁纸与水印；
   - 恢复时：平滑恢复所有窗口的平铺与几何布局，无缝继续工作。
3. **顶栏桌面按钮与 Walker 菜单集成**：
   - 在顶部 Waybar 右侧系统区域增加“Desktop (SUPER + D)”快捷图标按钮；
   - 在 Walker 启动器应用列表中注册“Show/Hide Desktop”命令。
4. **增强窗口关闭兼容性**：
   - 快捷键支持 `SUPER + C`、`SUPER + Q` 与 `SUPER + W` 同等触发窗口关闭；
   - 确保点击窗口右上角红点 🔴 能够即时稳定销毁当前窗口。

## Impact
- **视觉体验**：开机立即可见完整的 Omarchy 官方质感壁纸与白标水印，沉浸感倍增。
- **操作自由度**：用户可随意在“纯净桌面”与“高生产力平铺终端”之间一键切换。
